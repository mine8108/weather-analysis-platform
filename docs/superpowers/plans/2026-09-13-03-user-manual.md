# 用户使用手册体系化 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立 `docs/用户使用手册.md` 作为手册唯一真相源，在侧边栏提供独立入口并支持应用内阅读与现场导出独立 HTML；同时让手册内容与 2.4.0 的实际功能严格一致。

**Architecture:** `docs/用户使用手册.md` 是唯一被人工维护的手册文件（14 章）。`modules/manual.py` 负责加载、章节解析、应用内渲染与 HTML 生成；`app.py` 在登录门禁之后、主头部之前拦截 `_manual_open` 标志，渲染手册页并 `st.stop()`，因此**不占用 Tab 编号**，对 `active_tab`、`_nav_stack`、`_TAB_NAMES`、`_RESET_KEYS_BY_TAB` 与所有 `_navigate_to()` 调用零影响。HTML 导出用 `markdown_it`（streamlit 的传递依赖，已在本机验证可用）现场转换，不维护第二份文档。

**Tech Stack:** Python 3.12/3.14、streamlit 1.59、markdown-it-py 4.2（已是 streamlit 传递依赖）

**Spec:** `docs/superpowers/specs/2026-09-13-chart-reader-and-era5-delivery-design.md` 第 5.1 节（另需第 5.2 节写第 8 章、第 5.4 节写第 11 章）
**前置批次：** 批次 1（AQI 口径）与批次 2（ERA5）已完成；本批次手册必须反映它们的最终形态。

## Global Constraints

- 手册唯一真相源是 `docs/用户使用手册.md`；**不得**另建 HTML 副本或第二份 Markdown。根目录旧 `用户使用手册.html` 在第 5 批次删除，本批次不动它。
- 章节格式固定为 `## N. 标题`（N 为 1–14 的连续阿拉伯数字），节标题用 `### `。解析器与测试都依赖此格式。
- 手册中的事实必须来自代码，不得凭印象书写。凡涉及数量、名称、阈值、字段名、标准编号，必须能在源码中对应到具体位置。
- **AQI 口径必须如实写作 HJ 633-2012**（实际所用断点表），不得写 HJ 633-2026 或 GB 3095-2026 作为 AQI 的分指数依据。达标限值口径单独说明。
- **不得**出现已不存在的「再分析数据处理」Tab、「气候态」Tab 等字样。
- 手册正文**不得**含 `TODO` / `TBD` / `待补` 等占位标记。
- 本批次不修改 `config.APP_VERSION`（留到第 5 批次改为 2.4.0）；手册中的版本号由导出函数从 `config.APP_VERSION` 注入，正文不硬编码版本号。
- `modules/manual.py` 只依赖标准库、`streamlit`、`markdown_it` 与 `config`。
- 测试可 `python -B tests/test_manual.py` 直接运行，也可被 pytest 收集。
- 提交前必须跑通四个 CI 门禁脚本与 `python -B -m pytest tests -q`。

```python
"""用户使用手册：加载、章节解析、应用内渲染与独立 HTML 导出。

手册的唯一真相源是 docs/用户使用手册.md（14 章，`## N. 标题` 格式）。
本模块现场渲染与导出，不维护第二份文档，避免漂移。

设计取舍：应用内章节导航用 selectbox 而非页内 #anchor 跳转——
Streamlit 为标题生成的 id 依版本变化，跨版本会静默失效。
导出 HTML 的锚点由本模块自己写入，因此导出件内的目录链接始终可用。
"""

import html as _html
import io
import os
import re

import streamlit as st

from config import APP_VERSION

MANUAL_PATH = os.path.join(
    os.path.dirname(os.path.dirname(os.path.abspath(__file__))),
    "docs", "用户使用手册.md",
)

CHAPTER_RE = re.compile(r"^##\s+(\d+)\.\s+(.+?)\s*$", re.M)

_CSS = """..."""   # 蓝白学术风，沿用原手册配色（见实现）
```

- `load_manual_markdown()`：用 `__file__` 推导绝对路径读取，`encoding="utf-8"`；文件缺失返回空串（由页面提示，不抛异常）。
- `parse_chapters(md_text)`：用 `CHAPTER_RE` 切分，返回按出现顺序的列表；`body_md` 为该章标题之后、下一章标题之前的原文。
- `render_manual_page()`：顶部「← 返回应用」按钮（置 `_manual_open=False` 并 `st.rerun()`）；章节 `selectbox`（选项为「全部」+ 各章标题）+ 「下载 HTML」按钮；选中单章时只渲染该章。
- `render_sidebar_entry()`：`st.button("📖 用户使用手册", use_container_width=True)`，点击置 `st.session_state["_manual_open"] = True` 并 `st.rerun()`。
- `build_manual_html(md_text)`：`markdown_it.MarkdownIt("commonmark").enable("table")` 渲染正文；为各章 h2 注入 `id="ch-N"`；自动生成目录；内嵌 `_CSS`；页头写入「版本 APP_VERSION + 生成时间」。
