# 再分析数据处理 · 本地运行操作指引

> 适用对象：已在平台「再分析数据处理」板块获取到 ERA5 脚本（如 `era5_example_script.py`），需要在**自己电脑**上下载 CDS 数据并生成气候态宽表的用户。
>
> 前置条件：CDS 账号已注册完成（https://cds.climate.copernicus.eu）。
>
> 全程大约需要 20-40 分钟（不含 CDS 下载排队时间），共 5 步。

---

## 整体流程一览

| 步骤 | 做什么 | 需要动手的界面 |
|------|--------|----------------|
| 1 | 获取 API 密钥（UID 与 Key） | 浏览器（CDS 网站） |
| 2 | 创建 `.cdsapirc` 配置文件 | 记事本 / PowerShell |
| 3 | 检查并安装 Python | PowerShell |
| 4 | 安装 5 个依赖库 | PowerShell |
| 5 | 运行脚本，得到气候态宽表 | PowerShell |

第 1、2 步只需做一次，以后所有 ERA5 脚本都复用。

---

## 第 1 步：获取 CDS API 密钥

1. 打开浏览器，进入 **https://cds.climate.copernicus.eu**，点击右上角 **Log in** 登录（用你注册时的账号）。
2. 登录后，点击右上角你的**用户名**，在下拉菜单里找到并进入 **API key**（有的版本叫 "API key / Personal access token"）。
3. 页面上会显示三行信息：
   ```
   url:  https://cds.climate.copernicus.eu/api
   key:  xxxxxxxxxxxx:yyyyyyyyyyyyyyyy
   ```
   `key` 以**英文冒号**分隔，前面一串是 UID，后面是 Key，**两段都要完整复制**，漏一段都会认证失败。
4. （重要）**预先接受数据集条款**：新注册账号使用某个数据集前，必须先进入该数据集的网页，滚动到页面下方的许可条款处勾选同意。否则首次运行脚本会报"未授权"。示例脚本用的是 `reanalysis-era5-single-levels-monthly-means`，请在 CDS 搜索框输入该名字，进入页面完成条款勾选。

> 注意：API key 相当于你的账号密码，不要发给别人，也不要截图发到群里。

---

## 第 2 步：创建 `.cdsapirc` 配置文件

这个文件放在你的用户主目录（`C:\Users\ASUS`），cdsapi 运行时自动读取它完成认证。**文件没有扩展名、以点开头**，Windows 资源管理器不允许直接新建这种文件，所以要用"记事本另存为"法。

### 方法 A：记事本（推荐新手）

1. 在桌面空白处右键 → **新建** → **文本文档**，双击打开记事本。
2. 把第 1 步拿到的两行信息粘贴进去（把尖括号内容换成你自己的）：
   ```
   url: https://cds.climate.copernicus.eu/api
   key: 你的UID:你的Key
   ```
3. 菜单 **文件** → **另存为**。
4. 关键设置：
   - 保存位置：左侧选 **此电脑 → Windows (C:) → 用户 → ASUS**
   - 文件名输入：**`.cdsapirc`**（注意最前面有一个点，且**必须**用英文双引号把整个文件名包起来，防止它自动补成 `.cdsapirc.txt`）
   - 保存类型：选 **所有文件 (*.*)**
   - 编码：**UTF-8**（默认即可）
5. 点 **保存**。如果弹出"是否更改扩展名"提示，点**是**。
6. 回到桌面删除刚才新建的空白文本文件。

### 方法 B：PowerShell 一条命令（可选）

按 `Win + R`，输入 `powershell` 回车，粘贴下面命令（同样替换尖括号内容）后回车：

```powershell
Set-Content -Path "$HOME\.cdsapirc" -Value "url: https://cds.climate.copernicus.eu/api","key: 你的UID:你的Key"
```

### 验证是否配置成功

打开 PowerShell（`Win + R` → 输入 `powershell` → 回车），运行：

```powershell
Get-Content "$HOME\.cdsapirc"
```

能看到那两行内容就说明配置成功。如果显示"找不到路径"，说明文件没保存到正确位置，重新执行第 2 步。

## 第 3 步：检查并安装 Python

1. 打开 PowerShell，运行：

   ```powershell
   python --version
   ```

2. 三种情况：
   - 显示 `Python 3.9.x` 或更高版本（如 3.10/3.11/3.12）→ 直接进入第 4 步。
   - 显示 `Python 3.8` 或更低 → 建议升级到 3.9+。
   - 提示 `python 不是内部或外部命令` / `python : 无法将“python”项识别为` → 电脑还没装 Python，按下面操作：
     1. 打开 https://www.python.org/downloads/ 下载最新版安装包
     2. 安装时**务必勾选 "Add python.exe to PATH"**，再点 Install Now
     3. 安装完成后**关闭并重新打开 PowerShell**，再运行 `python --version` 确认

3. 如果电脑装了多个 Python（比如 Anaconda），建议固定用同一个，后续所有命令都在**同一个 PowerShell 窗口**里执行，避免混用。

---

## 第 4 步：安装依赖库

在同一个 PowerShell 窗口运行：

```powershell
pip install cdsapi xarray netCDF4 pandas numpy
```

- 如果提示 `pip 未找到`，改用：

  ```powershell
  python -m pip install cdsapi xarray netCDF4 pandas numpy
  ```

- 国内网络较慢或超时，可加清华镜像源加速：

  ```powershell
  pip install -i https://pypi.tuna.tsinghua.edu.cn/simple cdsapi xarray netCDF4 pandas numpy
  ```

- 安装结束后验证（能看到 OK 即成功）：

  ```powershell
  python -c "import cdsapi, xarray, pandas, numpy; print('OK')"
  ```

## 第 5 步：运行脚本，生成气候态宽表

1. 在磁盘上建一个专门的工作文件夹，例如 `C:\era5`（把脚本文件放进去）。
2. 把从平台下载的脚本（示例为 `era5_example_script.py`）复制到这个文件夹。
3. 在 PowerShell 中进入该文件夹：

   ```powershell
   cd C:\era5
   ```

   > 若你的文件夹名字不同，把 `C:\era5` 换成实际路径即可。PowerShell 支持复制粘贴文件夹地址栏路径。

4. 运行脚本：

   ```powershell
   python era5_example_script.py
   ```

5. 运行过程会依次出现：
   ```
   [1/3] 请求 CDS 数据集 reanalysis-era5-single-levels-monthly-means，排队+下载可能需要较长时间...
   [2/3] ...（下载中）
   [OK] 气候态宽表已输出: beijing_climate_climate_stats.csv
   [3/3] 完成。
   ```
   **下载是排队制**，等 30 分钟到数小时都正常，窗口保持打开即可，不要中途关闭。

6. 运行结束后，`C:\era5` 文件夹里会出现三个文件：
   | 文件 | 内容 | 用途 |
   |------|------|------|
   | `beijing_climate_download.nc` | 从 CDS 下载的原始数据 | 可留作备份 |
   | **`beijing_climate_climate_stats.csv`** | **气候态宽表** | **上传回平台用这个** |
   | `beijing_climate_processed.nc` | 处理后的数据 | 需要时自行分析 |

7. 回到平台「再分析数据处理」板块：
   1. 在"上传气候态文件"处选择 `beijing_climate_climate_stats.csv`
   2. 确认经纬度与脚本中心点一致（示例为 39.9N, 116.4E，可手动微调）
   3. 点击 **[导入] 获取气候态数据**
   4. 页面显示"气候态数据已加载"即闭环成功，之后的距平分析用的就是真实的 30 年 ERA5 气候态

## 常见问题排查

| 现象 | 原因 | 解决 |
|------|------|------|
| 提示"未找到 ~/.cdsapirc" | 配置文件没建或放错位置 | 重做第 2 步，确认文件在 `C:\Users\ASUS\.cdsapirc` |
| 报错 403 / Not authorized | 数据集许可条款未接受 | 到 CDS 网页进入对应数据集，勾选条款后重跑 |
| 报错 key 无效 / Unauthorized | key 粘贴不全或冒号不对 | 检查 `.cdsapirc`，确保 `key: UID:Key` 格式，冒号是英文的 |
| 下载到一半断网/中断 | 网络波动 | 直接重新运行脚本，cdsapi 会重新请求，数据不会损坏 |
| 排队很久没动静 | CDS 高峰期，属正常 | 耐心等待；体积太大时回到平台改用"月均值产品"再生成 |
| PowerShell 中文乱码 | 编码问题 | 先执行 `chcp 65001` 再运行脚本 |
| `pip` 装库报错红色文字 | 网络或版本问题 | 用第 4 步的清华镜像命令重试 |

---

## 小贴士

- **体积与时间**：月均值产品很小（北京 30 年 3 变量约 0.2 MB 数据量级），逐小时产品则可能几十 GB。仅做气候态统计一律选**月均值产品**。
- **一次配置，永久复用**：第 1、2 步做完后，以后从平台生成的任何 ERA5 脚本，直接放进 `C:\era5` 运行即可。
- **想改站点**：在平台向导里选"目标点小区域"并填入新经纬度，重新生成脚本，本地重跑一次即可。
