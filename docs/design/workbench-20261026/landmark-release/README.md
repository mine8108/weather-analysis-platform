## 验证边界

浏览器预览使用明确标注的合成数据，不代表实况。地标为装饰插画，建筑细部未按测绘资料复核。真实触屏、原生 200% 缩放和后台可见性事件仍沿用既有待验收项。后端验证已改用经用户授权的主项目；其只读检查与已有线上冒烟验证不扩展为成功路径、用户隔离或并发通过。本机缺少文档渲染器，Word 的实际分页、字体换行与人工版面验收仍未完成，下载内容一致不等于排版通过。本次未消费付费 AI 额度。
