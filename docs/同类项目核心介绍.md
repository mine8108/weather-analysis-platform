## 一、专业气象可视化

### 1. georgemulu/wrf_visualization_app
- **定位**：多页 Streamlit 应用，可视化 WRF 模式对肯尼亚区域的输出。
- **技术栈**：Streamlit + wrf-python + netCDF4 + matplotlib + cartopy + geopandas + metpy；Python 3.10。
- **核心能力**：风速/温度/降水/湿度多变量渲染、肯尼亚行政区边界叠加、自定义色标与气压层、统计值（min/max/mean）、双时刻并排对比、PNG 导出、从 Cloudflare R2 拉取 WRF 文件。
- **可借鉴**：专业模式变量的分层渲染范式、行政区地理上下文叠加。

### 2. AmadejKrepek/wrf-visualization-app
- **定位**：WRF 预报 vs 实况（ground truth）对比与验证的 Streamlit 应用。
- **技术栈**：Streamlit + xarray（惰性加载，支持 >1GB / 最大 5GB）+ Plotly。
- **核心能力**：多上传模式（单文件/多配置/本地）、自动识别实况、交互缩放悬停、MAE/RMSE/Bias/相关系数自动计算、时间序列对比/散点/误差分布/累积误差、最多 7 套配置同图对比、HTML/CSV/统计摘要导出。
- **可借鉴**：模型验证的误差指标自动化、多配置对比 UI、大 NetCDF 惰性加载。

### 3. anikfal/PostWRF
- **定位**：WRF 与 ERA5 模式后处理可视化工具集（NCL + Shell，非 Python Web）。
- **技术栈**：NCL + Linux Shell，namelist 风格配置。
- **核心能力**：WRF-NetCDF→GeoTIFF（GIS 对接）、ERA5 再分析绘图与提取、RTTOV 辐射传输模型输入输出处理、面向经验不足的环境研究者降低使用门槛。
- **可借鉴**：WRF/ERA5 一体化后处理思路、GIS 导出能力。

## 二、气候 / ML 预报

### 4. Sunnysain/Climate-Change-Prediction
- **定位**：新德里温度/降水 ML 预测交互仪表盘。
- **技术栈**：Streamlit + scikit-learn + pandas + Folium + matplotlib。
- **核心能力**：按日期预测均温与降水、多元联合预测、交互地图、历史趋势可视化。
- **可借鉴**：日期驱动的预测交互、地图叠加。

### 5. PSURI1894/climate_rainfall_realtime
- **定位**：端到端降雨预测，从 Open-Meteo 实时拉取全球历史天气训练模型（简历级项目）。
- **技术栈**：Open-Meteo API（无 key）+ scikit-learn RandomForest + 模块化 src/ 结构 + 可选 Streamlit。
- **核心能力**：任意地点动态取数（最长 ~80 年）、时序特征工程（lag/rolling/季节性）、随机森林回归预测次日降水、CLI 训练+预测+可选仪表盘。
- **可借鉴**：实时 API 取数替代静态 CSV、特征工程流水线、模块化目录结构。

### 6. siddharth277/Ensemble-weather-prediction
- **定位**：德里日均温集成预报，五大模型加权融合，Streamlit 交付。
- **技术栈**：XGBoost + LightGBM + 双向 LSTM + ARIMA + SARIMA + 手动调权集成；SHAP 解释；Streamlit。
- **核心能力**：实时滑块输入（温/湿/风/压 + 滞后项）、5 模型+集成独立预测卡、模型对比柱状图、RMSE/R² 参考表、缺失模型优雅降级。
- **可借鉴**：多模型集成与对比 UI、可解释性（SHAP）、缺失模型降级。

### 7. alex3ai/projeto-previsao-clima
- **定位**：温度预报混合模型，结合时序数据 + 卫星云图 CNN 视觉特征 + 大气动力（风/压）。
- **技术栈**：PyTorch + TorchVision(ResNet50 提特征) + OpenCV + Meteostat/Sentinel Hub API + Streamlit。
- **核心能力**：5 模块流水线（采集→卫星图同步→CV 特征提取→PyTorch 训练→实时仪表盘）、CNN 特征向量拼接数值特征预测次日温度。
- **可借鉴**：卫星图像多模态融合、CV 特征工程接入数值预报。

### 8. Tanishaaaaaaa/StormShield（AI 洪水卫士）
- **定位**：黑客松产出的实时洪水预测与市政预警系统。
- **技术栈**：FastAPI 后端 + Streamlit 前端 + Folium + Plotly + XGBoost（时序预报）+ Gemini 2.0（告警生成 + RAG 问答）。
- **核心能力**：实时水文遥测、预测洪水图表、交互洪泛区地图、传感器标记、绿色基础设施模拟器、RAG 聊天机器人。
- **可借鉴**：ML 预报 + LLM 告警/RAG 的工程架构、前后端分离（FastAPI+Streamlit）。

## 三、与 weather_app 的对标小结

| 维度 | 同类项目常见做法 | weather_app 现状 |
|---|---|---|
| 数据来源 | 实时 API / 静态 CSV / 专业模式输出 | 用户上传 + GFS 预报 API + 气候态 |
| 可视化 | matplotlib / Plotly / cartopy 地图 | Plotly + 国标预警判定 |
| ML 预报 | 单点回归 / 集成 / 卫星 CV 融合 | GFS 数值预报（非统计 ML） |
| 多用户 | 极少（多为单人 demo） | Supabase 私有隔离 + 邀请码 + 配额 |
| 数据录入 | 表单输入为主 | SYNOP/METAR 报文解码（专业通道） |

**可补强方向**：模型验证指标（MAE/RMSE，对标 #2）、实时 API 自动取数（对标 #5）、ML 集成与可解释性（对标 #6）、卫星多模态（对标 #7）、LLM 告警/RAG（对标 #8）。
