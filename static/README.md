# Public artwork

This directory contains only application-owned static assets. Do not place user uploads,
generated analysis results, credentials, or private datasets here.

Weather delivery files are generated by tools/prepare_weather_assets.py from the
original images in assets/weather/source.

City landmark delivery files are generated by tools/prepare_landmark_assets.py.
The 41-city catalog and per-file hashes are in assets/landmarks/. Original RGBA
artwork is retained in the local release archive; it is not required to run or
test the deployed app. Restore the source folders from that archive before
rebuilding artwork. All runtime images are committed under static/weather/.
